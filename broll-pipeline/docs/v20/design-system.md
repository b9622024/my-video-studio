# 可樂吉視覺語法引擎 V2.0

本分支為後續主線的風格驗證基底；保留所有舊系統，並未改寫 GitHub 預設分支。

## 視覺原則
以單一空間與可追蹤物件推進敘事。米白背景、墨綠主線、鼠尾草綠／麥色／柔黃區域；顏色固定對應語意。幾何區塊不是擬真食物，三區不是營養建議比例。所有數值僅為構圖參數，不顯示為飲食建議。

540×960 邏輯畫布，30fps；38px主標、19px說明、17px物件標註、13px眉題；左右安全邊界38px。字型 Noto Sans CJK，系統需安裝繁中版本。主描邊2.4px，次線1.2px。無投影、粒子與裝飾框。間距採8/16/24/32/48。精確色碼見 style-tokens.json。

## 六個可重用原型
BuildUp：容器外輪廓與分區依序建立；regions可換比例。
Portion：同容器分區與active強調；values可換，必須非負且總和為1。
Comparison：同尺度多狀態展開，values與labels可換。此原型上限三項。
Flow：文字節點與方向依序揭示；適用流程，不能僅用箭頭宣稱因果。
Spectrum：連續程度位置；不以中點作推薦答案。僅在Sampler驗證，不塞進本片。
Mechanism：同空間局部聚焦；不是自動生成醫學剖面。本片使用同樣的平移／縮放語法，Sampler展示可包裝子物件的元件。

## 資料與適用範圍
scene-presets.json 控制標題、標籤、比較狀態、輸出規格。此版為六模組原型與餐盤preset，尚非任意JSON自動編排引擎；新主題須替換幾何／元件組合，但不需重建Remotion。器官、建築、杯子應建立自己的輪廓資料，不能把餐盤圖稱作通用物件。

可沿用相同語法製作：杯水觀察（BuildUp→Spectrum）、流程說明（Flow→Mechanism）、方案對照（Comparison）。內容的數據、因果與比例仍需各題查證。
