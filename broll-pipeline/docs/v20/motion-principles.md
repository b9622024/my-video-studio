# 動態原則與事件表

所有時間由 useCurrentFrame 派生；沒有隨機值、DOM時鐘、外部GSAP。quintic smootherstep端點速度與加速度歸零。相機為正交平移與等比放大，非物理攝影模擬。

|時間|開始→變化→結果|語法|
|---|---|---|
|0–3秒|空盤→描出輪廓與三個區域→建立整餐參照|BuildUp、Portion|
|3–6秒|三區共存→依序強調蔬菜、蛋白質、主食→恢復整體|Portion、Flow|
|6–9秒|同盤→連續靠近主食位置→保留鄰區作參照|Mechanism語法|
|9–12秒|同盤退回→展開同尺度三盤→展示三種相對選擇|Comparison、Portion|

標題在每段開始以14影格遮罩揭示，不做彈跳；重要概念以區域明暗而非閃爍／發光呈現。鏡頭只為建立整體、辨認局部、建立比較而移動。末段先收鏡再展開，結尾保留約1秒辨認狀態。三盤是概念比較，不是真實添飯、不表示時間先後或推薦比例。
