# 美術與節奏自查

定位：12秒風格驗證候選，尚未人工核准，也未取代任何舊版正式核准紀錄。

已實看構圖：建立後整盤、逐區觀察、主食聚焦、比較展開、結尾。修正了早期標註方位錯誤、放大侵犯標題區，以及三盤超出畫幅的問題。主要食物區塊使用固定語意配色；最終比較有圖例可追蹤主食，不以任一選項作正解。

動態：前段描邊建立物件；中段變更注意力而不是更換整個版面；主食聚焦連續平移；最後同一容器收鏡展開，沒有照片或擬真動畫。標題只輔助分段，不承擔所有資訊。無音軌。

限制與待驗收：
- 抽象餐盤可辨認整體與區域，但未讀標註時無法辨認真實食物種類；這是本輪簡化視覺方向的取捨。
- 末段三個盤面約160px直徑，需在iPhone上確認辨認差異的舒適度。
- 幾何分區仍有圖表感；是否達到「非PPT、可作系列主線」應由人工實看節奏決定，不把渲染成功等同通過。
- 主片未塞入Spectrum，避免無意義滑桿；Spectrum與Mechanism元件以獨立Sampler影格示範。
- 目前是可重用元件及餐盤preset，不宣稱已完成任意題材全自動視覺編排。

待確認：整體留白與主體尺寸、最後比較停留時間、線條與文字細度、是否接受這組品牌配色作後續系列基底。
