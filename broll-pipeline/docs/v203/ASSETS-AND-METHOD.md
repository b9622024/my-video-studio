# 實際資產與製作方式

|資產|來源|A使用|B使用|
|---|---|---|---|
|101塔身|既有v202-motion/SceneObjects.tsx的Tower原檔|同一原造型，低對比外牆|同一原造型，較深外牆參照|
|運動／幾何|既有MotionModel.ts與config.json原檔|完全沿用|完全沿用|
|金球|原半徑17、原鋼板弧線的精簡變體|柔和漸層、四條材質線|加強同向體積明暗及牆面投影|
|吊索／托架|原錨點與geometryAt端點|深藍灰清晰輪廓|淺色金屬線、前後遮擋|
|油壓連桿|原端點、原固定缸體長度|淺綠缸體與深桿|金屬明暗與前景遮擋|
|剖面場景|本輪原創SVG路徑|淺色牆／柱／樓板|平行投影側牆、後壁、樓板與梁上表面|
|陰影／材質|本輪SVG gradient與少量blur|主要為物件材質漸層|一個受控牆面投影與物件明暗|

全部為可分層向量。ArtStudy.tsx內分成背景／外牆、室內平面、支承與吊索、球體、托架與連桿、前景樓板；每幀由Remotion合成。不是整張生成圖片縮放，不使用新圖像模型、付費素材、GPU或新服務。

新檔案只實作本次場景，不新增大型元件庫，也沒有修改六大視覺模組。光影是插畫規則，沒有宣稱物理光線追蹤。
