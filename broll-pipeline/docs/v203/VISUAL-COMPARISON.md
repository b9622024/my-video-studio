# 動態美術比較自查（非人工驗收）

已檢查A／B實際MP4抽出的同幀序列，以及1080母檔的原生frame75。評估為製作者判斷，沒有實體手機、獨立觀眾或使用者正式美術驗收。

## 觀察

|項目|A 精緻技術插圖|B 編輯式2.5D|
|---|---|---|
|物件辨識|輪廓清楚，吊索與連桿色差明確|球體與暗色空間的光比更強，體積較容易讀取|
|構圖焦點|外牆壓低對比，淺底減少干擾|內部深淺平面與前景樓板圍出裝置位置|
|空間層次|保留建築輪廓與梁柱，深度較弱|有側牆、後壁、前景梁板及球體投影，較接近參考的空間感|
|機構可讀性|缸體、桿件與底部關節較完整|明暗對比好，但前景樓板會遮住部分底端關節，是深度與解說完整性的取捨|
|動態|同一球體往返，纜索角度及活塞外露長度變化|完全相同物理動作，另有隨物件移動的受控投影及結構遮擋|
|手機縮圖|淺色桿件輪廓仍可辨認，但色差比B弱|球體較突出；原生尺寸之外未做實體手機測試|

兩版都在1.5秒後固定鏡頭，只保留裝置與建築的相對動作；沒有持續推拉、跳切或單張圖片縮放。模型、球體半徑與連接位置沒有因版本而改變。

## 方向判斷

**B較接近本次參考影片的主體光比與空間層次；A更適合批次機制解說與跨主題重用。** 這是製作者的相對比較，不等於B已達正式發布品質。

## 現有程式向量方案的美術限制

- A仍明顯是技術插圖，即使減少結構，也不會自然變成有豐富鏡頭感的編輯插畫。
- B的側牆是固定平行投影，球體體積主要由漸層及少量投影表達；仍帶有剖面舞台盒的感覺，沒有複雜曲面、真實材質或多角度資產。
- 兩版共用同一正面機構投影。這對受控比較公平，但限制了側面構圖、前後錯位與空間探索的豐富度。
- 更多陰影、線條或粒子不能自動解決以上問題；若人工仍判定像工程圖，應調整原創物件／場景的美術資產，而不是繼續堆疊效果。
- 四秒只能檢查進入、揭示與機構運作，不能當作完整八秒敘事已改良的證據。
