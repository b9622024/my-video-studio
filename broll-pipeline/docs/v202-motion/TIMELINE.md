# 四鏡實作時間軸

|鏡頭|影格（右端不含）|時間|事件與閱讀安排|
|---|---|---|---|
|S01|0–54|0–1.8s|前0.3秒穩定城市；風線先進場，0.6秒起受力；塔身小幅撓曲、地基固定。最後0.6秒微幅準備靠近|
|S02|54–105|1.8–3.5s|連續追蹤同一上層，對數尺度推近；72–101幀剖開局部外牆，梁、吊索、球及連桿依空間遮擋被看見|
|S03|105–180|3.5–6s|鏡頭完全固定；建築框架與質量耦合運動，吊索角度及活塞桿外露長度改變。裝置持續運作，不突然凍結|
|S04|180–240|6–8s|直接切到兩個相同尺度、相同地線及外力的概念實例。未設裝置的塔身反應較大，設有裝置者較小但非零；短暫塔尖軌跡取自過去12幀的實際模型投影|

沒有全畫面文字卡。主版本只在比較鏡加入身份標籤；no-labels版本移除身份標籤，兩版均保留必要的「概念示意，非實測・仍有晃動」。兩版無音軌。

本片的Settle是相機保持、讓觀眾讀取持續運動的結果，不表示建築或球完全靜止。結尾不淡出、不轉品牌頁。
