# 阻尼球簡化耦合模型

本片是無因次教學示意，不是台北101工程模擬、真實晃動週期、實測擺幅或減振百分比。參考的基本裝置角色見[101官方說明](https://www.taipei-101.com.tw/en/observatory/feature)：懸吊質量與液壓阻尼構件配合減振；本片沒有使用官方工程參數。

## 同時求解，不指定反向

x是建築在裝置位置的水平自由度，y是質量的絕對水平自由度；另一個z是未設該裝置但建築質量、剛度、結構阻尼與外力相同的比較解。

```
M x'' + cb x' + kb x + cd(x'-y') + kd(x-y) = F(t)
m y'' + cd(y'-x') + kd(y-x) = 0
M z'' + cb z' + kb z = F(t)
```

所有值為自選的無因次示例係數，保存在config.json；並非對台北101的估計。沒有使用y=-x。球的慣性、懸吊回復及阻尼回饋共同決定相位；序列中既有同向、也有異向運動。阻尼耗能項為cd(y'-x')²，始終非負；程式檢查其與系統能量收支一致。

外力為平滑起始的正值均值加正弦擾動：影片0.3秒風線開始抵達，約0.6秒到外牆，模型才開始受力。右向風的合力不反向。風線只作方向符號，不是風速儀表或外力波形量測。兩個比較解在同一時刻、相同F(t)下計算，不重新啟動、不對其中一邊減弱風力。

## 積分與圖像映射

RK4，步長1/600影片秒，每30fps採樣；用半步長複核收斂。這裡的影片秒不是實際建築週期。相同的單一顯示增益同時映射x、y、z，不各自縮放來製造比較效果。

顯示增益由全段的相對位移選成可讀且不碰牆的範圍，**不是逐幀截斷**。建築上部採二次模態形狀，底部位移為0；x對應裝置樓層，換算到塔尖。這是示意的撓曲形狀，不是有限元素分析。城市不受這個位移影響。

球相對位移r=y-x決定吊索角度；同長的兩束投影吊索以圓弧高度修正垂直位置。球、托架及關節共用同一個中心；下方兩支投影連桿的缸體長度固定，只有活塞桿外露長度改變。構件數量為投影簡化，不代表真實總支數。

幾何高度修正為小角度線性動力學外加的視覺約束，不是完整非線性擺錘模型。沒有展示真實長度、質量、速度或百分比。

## 測試能證明與不能證明的事

已測：有限狀態、延遲受力、正值共同外力、耦合能量收支、步長收斂、非固定反相、吊索等長、球及托架不越出剖面、缸體不頂死、比較解有較小但非零的反應。

上述只驗證此示意模型和幾何程式，不證明真實101的減振性能，也不證明觀眾已理解畫面。人工視覺驗收保持未通過狀態。

本例刻意讓外力擾動頻率接近示例建築頻率，便於觀察調諧裝置的作用；不表示所有風況都固定出現相同差異。這是概念模型的展示條件，不是對真實101的性能保證。
