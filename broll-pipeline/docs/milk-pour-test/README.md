# 牛奶倒入｜單一近景動態驗證

依使用者明確確認的 milk-pour-art-review 插畫製作。僅三秒、90影格、30fps，無配音、無音樂、無字幕；沒有15秒影片或多場景模板。動態美術仍待人工驗收。

## 本次處理

- 大杯位於下半部，紙盒位於右上並有意裁切，構圖不退遠、不切鏡、不靠整張圖縮放。
- 以已核准原圖為唯一參考，利用現有圖像編輯工具分別整理空杯與完整紙盒兩個RGBA物件；沒有沿用舊版Objects.tsx美術。兩張編輯輸出仍有生成差異，不宣稱逐像素等同核准原圖。
- SVG受控遮罩限制杯口前後、杯壁及紙盒外緣；裁掉透明層周邊暈光。杯內液體、液面、流線與輕微落點波紋是獨立可控物件，不交換整張圖片。
- 0–0.5秒小幅盒身預備動作；0.5秒開始液流、約0.73秒抵達；接觸後液面上升；2.2秒源頭進入收束、約2.37秒流尾排空；約2.77秒後保持穩定完成畫面。這是概念液體動畫，不是流體模擬或容量量測。
- 前後杯緣及厚杯底保留透明感；光影本身不隨機更新；固定鏡頭避免干擾。

## 與上一版差異及限制

對比V2.2：主體明顯放大，改用已核准插畫的折面、冷暖色與厚玻璃造型；沒有品牌列、文字卡、比較頁或餐桌展開。舊新版對照為相同540×960視窗，不是相同時刻的兩個物理模擬。

仍有風險：杯壁高光與牛奶交界是分層合成，局部邊界仍可能顯得人工；液體是設計化幾何，並非自然流體。紙盒以盒口為固定錨點作小角度運動，沒有手持動作。原圖與編輯資產是光柵，放大後邊緣精細度受限。不能以成功渲染判定已達品牌級或人工驗收標準；本輪沒有真人／實機觀看測試。

## 輸出及重建

1080×1920版本由Remotion原生合成；540×960由同一成片Lanczos縮小。全部H.264、yuv420p、3秒、30fps、無音軌。原始物件像素數不代表全部素材原生1080；無法觀察平台是否另行轉碼。尺寸、SHA256及資產尺寸見verification.json。

沿用既有Remotion主機與Chromium，沒有新套件或付費服務：

```bash
node tools/render-milk-pour-test.mjs
ffmpeg -i /workspace/outputs/milk-pour-test/milk-pour-test-1080.mp4 -vf scale=540:960:flags=lanczos -c:v libx264 -crf 18 -pix_fmt yuv420p -an /workspace/outputs/milk-pour-test/milk-pour-test-540.mp4
```

工具支援`--stills`只輸出0、24、48、84影格。完整解碼、尺寸／影格數與TypeScript已檢查；未修改配音、Pixabay、HyperFrames、歷史Composition或任何舊版美術。
