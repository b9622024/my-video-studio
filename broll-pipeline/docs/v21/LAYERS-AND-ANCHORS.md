# 原創圖層、錨點與前後關係

所有座標先在1024×1536的同一原生場景平面；camera再投影到1080×1920。不是工程尺寸或樓層測繪。數值為製作者依圖像放置，允許少量像素誤差。

|順序|層|資產／方式|可控制範圍|
|---|---|---|---|
|0|固定內部與外側結構|scene-interior.png|完整底圖；可作同一結構群的定位參照|
|1|質量投影|shadow-layer.png／MassShadow向量|可獨立移位與調強度；非物理光線追蹤|
|2|吊索|suspension-layer.png／Suspension向量|四條投影鋼索的起點、終點均由錨點決定|
|3|金球|mass-gold.png，真實alpha|獨立位置、尺寸、pivot；自帶同光源材質|
|4|承托架|cradle-front.png，真實alpha|獨立圖層；之後應與質量作剛性綁定|
|5|油壓缸與活塞|hydraulic-body.png+Rods向量|兩個同規格缸體實例，固定尺寸；活塞桿依端點長度改變|
|6|外牆揭示|facade-layer.png|從生成的閉合外牆來源，只取同一入口多邊形；可獨立遮罩，不替換全場景|
|7|近側柱面與樓板|foreground-layer.png|從固定底圖取完全註冊的前景matte，在動物件之前遮擋|
|8|必要資訊|概念註記|只有「原創插畫・概念示意」，無敘事字幕|

前景matte的像素也存在於固定底圖，這是標準前後遮擋合成：重疊的是同位置的固定結構，沒有複製金球或用貼圖假造多個食物／物件。底圖沒有金球、吊索或油壓連桿。

主要錨點（場景座標）：

- 上梁吊點：左(409,628)、右(667,628)。
- 質量／托架組的下端連接：左(391,1019)、右(685,1019)。
- 固定柱腳連桿點：左(248,1094)、右(830,1101)。右端被部分前景柱面遮擋。
- 金球pivot：(538,853)；對應素材local pivot約(627,644.5)。
- 缸體local mount：(175,354)，local outlet：(2078,354)，兩者決定素材的放置與朝向；不是任意整張圖片縮放來伸長缸體。

完整rect、native尺寸、camera、layer z與揭示量在scene.json；圖像定位圖為anchor-map.jpg。可以修改scene的錨點重新輸出獨立向量層，沒有將鋼索端點畫死在背景裡。

## 動畫可行性：有圖層，不等於已通過rig驗證

原V2.0.2的stateAt、耦合模型、影格時序可沿用，沒有重新開發物理系統。但新資產的透視、吊點跨度與承托架形狀不同，**不能直接把舊像素位移硬套上去**。

下一階段須驗證：原模型到插畫座標的投影、吊索長度與托架姿態、油壓行程、球體／托架接觸、近側柱遮擋。新吊索在圖像平面不是舊版的理想平行雙索，因此不能聲稱已完成等長擺動驗證。

固定底圖的建築、室內梁柱與遠景目前烘焙在同一層；不能拿它直接做外觀獨立撓曲、又聲稱遠景不動。三秒段的室內共移須另規劃固定環境與結構投影；如需外部明顯獨立擺動，必須補乾淨遠景與建築matte。這是現有資產限制，不以整張插畫搖晃假裝解決。

目前狀態：**美術層可獨立控制；動態rig尚待驗證；人工美術核准待辦。** 因此本輪沒有進入三秒動畫。
