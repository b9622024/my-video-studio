# 與V2.0.3對照與方法限制

對照使用V2.0.3 B原生1080母檔的frame0／36／75，分別對應「上層定位／進入剖面／特寫」；新圖也是1080×1920。這是**相同敘事階段與輸出尺寸**的美術比較，不是同一物理時刻、相同相機或相同工程幾何的A/B測試。新圖為靜態rest pose，不假裝已跑原模型。

|內容|V2.0.3|V2.1|
|---|---|---|
|主體|SVG球、剖面盒、線條缸體|新繪製金球、承托架、缸體與建築場景|
|空間|簡化固定平行投影|新繪製的三分之四建築／室內透視、前景柱與樓板|
|材質|程式漸層與簡單投影|獨立插畫素材中的形體、板縫、紙面與金屬筆觸|
|可動性|已有動態與幾何測試|圖層已拆開並有錨點；新投影的動態尚未驗證|
|重用|程式物件與控制器|原模型／時間軸可留用，圖像資產按題材製作，需錨點註冊|

可以沿用：Remotion環境、renderStill、圖層／遮罩、資料化camera、原耦合模型與測試習慣。

不能直接沿用：舊球形幾何、舊盒景、舊像素長度及舊理想雙索的投影。這些不是換色可解決的問題。

新方法的成本：需要真正的美術素材、可拆分的alpha、空間位置與遮擋設計；不適合宣稱所有主題只換一個prompt即可自動完成。若生成物件的透視／接觸不合，須補圖或重設rig，不用交叉淡化／整圖縮放掩蓋。

如果人工判斷仍不符合所需精緻程度，或覺得此版太像建築水粉而不夠極簡，停在美術階段，不以動畫特效試圖挽救。本輪不建立大型元件庫。
