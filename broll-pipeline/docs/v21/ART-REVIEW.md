# V2.1 第一階段｜Asset-first 美術驗收

## 本輪交付狀態

三張1080×1920關鍵畫面使用**同一組場景、金球、承托架、缸體、吊索與遮擋層**合成。A／B／C不是三次獨立生成，也不是一張含球的完整圖不斷裁切後宣稱互動。

- A：外牆閉合，可見上層與分節外觀。
- B：同一外牆的局部剖切，內部、吊索與金球開始被看見。
- C：同一裝置的清楚特寫，金球、承托架、兩個投影油壓連桿與梁柱同場。

這是原創概念建築插畫，不是台北101實測或施工模型；新上層採101分節與玉色玻璃的辨識語彙，未宣稱建築細節完全準確。

## 美術方向與V2.0.3的差異

本版重新製作了建築背景、外牆材質、金球、承托架和缸體。它們具有不同於舊SVG的輪廓、表面筆觸、機械形態與透視；不是舊圓形換色／調漸層。吊索與活塞桿保留可控制向量，因為它們必須連到各自端點；向量不再承擔主要球體及建築美術。

製作者自評：本版的材質層次、空間與物件質感相對V2.0.3有明顯變化，較接近資產先行的插畫製作。但仍需人工確認，尤其是：

1. 目前偏建築水粉插畫，細節比最終「具象化極簡」可能需要的更多；不能把細節多當成品牌風格已通過。
2. 原生建築底圖1024×1536，C鏡靠近時背景會插值放大；球與機械素材有較高獨立解析度，仍需手機看邊緣與細節。
3. 金球與承托架來自不同的同風格生成資產，接觸弧面看起來接近，但不是工程上精確匹配的三維表面。透明邊緣與接縫仍須人工檢查。
4. 右側油壓缸底端部分在近側柱面後方，作為合理前景遮擋；這也會降低底端關節可見性。
5. B的剖切邊緣目前是靜態美術示意。真正的揭示節奏、牆厚、遮擋連續性尚未驗證。
6. 沒有獨立觀看者、實體手機或人工正式核准，不能宣稱辨識度／美術通過。

## 第一階段否決規則

若人工認為仍未明顯優於V2.0.3，或不符合品牌極簡程度，停在本階段修美術，不開始動畫。即使製作者認為有改善，也須收到使用者核准，才製作3秒測試。
