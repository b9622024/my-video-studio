# 素材生成方式與來源

使用環境已具備的image_gen圖像生成／編輯能力；沒有開通新的外部付費API、GPU或素材服務。模型名稱與seed未由工具提供，不捏造。全部為本輪生成的原創概念插畫，沒有取用參考影片畫面。

## 製作順序

1. 生成固定上層建築與空的懸吊室。初稿過於細密，僅留作歷史草稿。
2. 以同一初稿編輯，移除大部分小窗格／小機械，改為較克制的建築水粉筆觸，維持同一空間。
3. 以該風格來源製作獨立透明金球；另編輯一張閉合外牆材質來源，最後只取其中固定入口四邊形，不把全張影像作另一關鍵畫面。
4. 同風格生成透明承托架與缸體；它們與金球分開，未烘焙入底圖。
5. 依安裝方案移除底圖中兩個未使用的中間柱腳小座，保留兩側結構柱腳作固定支承。最終底圖為scene-interior.png。
6. 在Remotion中定位資產、製作外牆／前景alpha matte、吊索及活塞桿向量，組成同一場景的A/B/C。

三張關鍵畫面不是三次圖像生成。底圖、金球、托架等的SHA與原生尺寸見asset-manifest.json。

- 金球透明PNG1254×1254：圓潤但有鋼板邊緣形態、少量水平板縫、繪製金屬質感，左上光；不可有球以外背景、吊索、承托架或外部投影。
