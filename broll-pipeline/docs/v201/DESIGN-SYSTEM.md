# 可樂吉健康研究所｜視覺語法 v0.2

V2.0.1 是造型與動作的跨主題原型驗證；不重建引擎，不替換 V2.0。正式風格尚待人工核准。

## 具象化極簡

簡化細節，保留特徵。以專用 SVG 路徑建立物件，不把生活物件換成統計圖形；本輪不使用擬真食物圖片、通用 Icon、圖像生成、付費服務或 GSAP。

背景 #F6F3EC、輪廓 #182F40、鼠尾草綠 #8FAA96、柔黃 #E3B35F、橘 #E58C58、灰 #7B8589。每幕以紙色、墨色和綠色為主；餐盤僅以少量橘色協助分辨蛋白質。白色為米飯／液體材質，不以彩色填滿盤面。

540 邏輯畫布：主輪廓3.4px、次線2px、輔助1.3px；相當於1080的6.8/4/2.6px。米粒細節1.5px；輪廓採圓接角。標題32px為原型識別字；收束說明22px，品牌14px。正式標題可採tokens中的38px。無文字測試版不畫任何可見文字。

視角以淺層次的物件示意為主：建築正立面、杯子正面帶橢圓杯口、餐盤由斜上方觀察。各物件內部視角一致；不強迫所有物件共用相同透視。陰影只作接地，無浮動或假立體旋轉。

## 可重用元件

- `Taipei101(frame,timing)`：具身份的專用輪廓，八段塔身與塔尖；不是所有高樓的通用造型。
- `MilkCarton(angle,spout)`、`Glass(surface)`、`MilkPour(angle,surface,front,tail,spout)`：可拆用容器與液體互動。
- `Rice`、`Vegetables`、`Protein`：各自獨立向量圖層，可用父層 transform 調整尺寸位置。
- `Plate(frame,timing)`：餐盤及三種食物的繪製揭示，沒有營養比例數據。
- `milkState(frame,config,timeline)`：前緣、尾端、液面與傾斜的影格狀態，無隨機值或DOM時鐘。

原創 SVG 位於 projects/recognizable-v201/assets，可直接編輯路徑。React元件是動畫來源；SVG由同一份元件匯出，避免維護兩套造型。時間與牛奶狀態參數在prototypes.json。adapters內JSON為編譯副本，渲染前工具會同步專案JSON。

## 與 V2.0 的具體差異

扇形→獨立食物輪廓；圖例→物件本身的可辨認特徵；持續鏡頭運動→固定鏡頭觀察事件；單題12秒→三題各2.5秒；語意自我推論→有紀錄的製作者檢查與待辦人工辨識測試。保留Level1用於真實量化資料，本輪沒有百分比、推薦份量或醫療主張。
