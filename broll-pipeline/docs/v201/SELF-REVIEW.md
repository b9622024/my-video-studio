# 造型與動作分開評估

評分為Codex製作者自評（1～5），不是觀眾研究，不是人工驗收。造型自查已在完整影片前完成，動作分數待實際影片抽幀檢查後記錄。沒有實體手機測試；手機可讀性僅以540畫布及270縮圖估計。

|原型|辨識度|造型完整性|美術一致性|手機可讀性|
|---|---:|---:|---:|---:|
|A 101|4|4|4|4|
|B 杯與紙盒|4|4|4|4|
|C 多食物餐盤|4|4|4|3|

造型依據：A保留八段外擴、收窄冠部與塔尖；B杯口／杯身／液面不同於單一矩形，紙盒有折頂與開口；C飯堆有米粒、菜有葉脈花蕾、肉片有不規則輪廓與烤紋。

風險：A仍需人類確認能否無提示說出101；B白色液體可被看成其他飲料，不憑杯子保證牛奶身份；C蛋白質可能被看成魚排，米粒小尺寸可讀性需手機實看。這些不以字幕掩蓋。任何關鍵項低於3就先修正該物件，不擴大製作。

本輪修正：紙盒傾斜時場景遮罩曾裁掉右角，已放寬場景遮罩；飯粒由圓點式記號改細長紋理並降低飯堆規則扇貝邊緣。保留原創簡化風格，未導入擬真食物圖或外部Icon。

已完成實際MP4抽幀檢查後的動作自評：

|原型|動作意義|因果關係|動作節奏|視覺連續性|
|---|---:|---:|---:|---:|
|A 101|4|4|4|4|
|B 杯與紙盒|4|3|4|4|
|C 多食物餐盤|3|3|4|4|

A：輪廓→塔身分節→塔尖→完整建築，沒有鏡頭漂移。B：液流與杯內上升有先後關係；開口作固定樞軸、流量未作物理計算，因此因果擬真程度僅評3。C：依序建立食物類別，屬結構揭示，不是實際食物互動；因此動作意義與因果均保守評3。

觀察實際MP4抽出的開始、過程、完成影格；另以來源影格63與74逐位元比較，三組完成狀態保持一致。完整解碼與相同影格只能證明技術穩定，不證明觀眾理解。最終仍需人工觀看三支無文字片。
