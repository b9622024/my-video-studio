# Object Recognition Gate｜人工測試表

尚未招募觀看者，沒有完成真實觀眾測試。Codex 自評不能取代本表。最終由人工驗收。

建議找3位不熟悉內容的人。先不要給他們檔名解答、標題版、特徵清單或此專案說明。由主持人依序顯示blind-test目錄中的中性代號影片，並記錄原話。可先顯示對應completion.png約1秒，再播放影片。一次完成後才揭示答案。

初始門檻：至少2/3辨認主要物件類別。建築另記是否能無提示說出101；杯子不要求只憑透明杯確認牛奶，接受「紙盒倒白色飲料入杯，杯內液體變多」；餐盤需辨認多種食物，不必猜肉品品種。

每位受試者請以自己的手機、正常觀看距離及比例顯示；不要只放大看細節。若任一關鍵造型或動作自評／人工評分低於3，先修正該物件再擴大製作。本輪沒有正式風格升級、沒有公開素材核准。
