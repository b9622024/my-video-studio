## 三場景驗收

- A：刀叉切餐盤肉／沙拉（227128）、削小黃瓜（45101）均不證明裝便當；不保留精確候選。初探紙箱包裝（8686）及處理生豬肉（11645）也不符合。替代：自行拍攝餐盒裝餐，或明示為示意動畫。
- B：11605 可見煮綠葉菜、筷子攪動及約36–39秒鍋鏟撈菜。另檢視0、2…52秒的影格序列；撈起後剪接成品，沒有連續放入餐盒證據。保留為近似方案，action_verified=false；請特別觀看34–40秒。11661羊肉燉胡蘿蔔成品排除。替代：自行拍攝夾熟蔬菜進便當。
- C：11626確有熟白飯，但沒有盛取動作證據；11623牛肉蓋飯成品也無盛飯證據。熟白飯特寫可作替代構圖，不能冒充盛飯。稻田、收割、農業及稻穀均排除。替代：自行拍攝飯匙盛熟飯，或無數值份量示意。

三場景都標記 no_suitable_footage，意思是沒有已確認精確動作匹配；B近似方案是待使用者判斷的候選，不是自動驗證成功。影格抽樣不能證明全片絕無某動作，保守排除表示目前證據不足。

舊9支逐筆比較見 test-results/v101-quality.json；餛飩、餐廳用餐、雨中番茄、稻田／農業均已被明確規則攔阻。舊版其餘未實看者維持 metadata_only，不把metadata排除寫成視覺驗證。

## 搜尋與存取實測

沿用官方 PixabayClient、24小時快取、每run6次／每分鐘8次／每日60次上限及429冷卻。先檢查舊3筆快取；新方向第一輪6次官方請求，第二輪重用6筆並新增3次，兩輪間已超過1分鐘。總共9次新API搜尋，沒有錯誤。不是用mock替代本輪真實搜尋。

小規模取得9支不同官方tiny影片作探索；最終審核包只含6支預覽。每檔來源20MiB上限、依API提供URL取得、不用第三方代理、不繞過403。GET失敗的素材記為unavailable；不因HEAD403先判失效。

|代表端點（227128）|本輪HEAD|本輪GET|
|---|---|---|
|API tiny mp4|200 video/mp4|200 video/mp4，實際下載／轉碼成功|
|API tiny jpg|200 image/jpeg|200 image/jpeg，170755 bytes|
|來源 id 頁|301|301|
|301提供的官方canonical頁|200|200|

前輪Python HEAD報告為403。本輪相同Node正式代理路徑的HEAD及GET皆200；不能把差異單獨歸因於方法、金鑰、revision或確定的防爬原因。來源id頁本來會重新導向，最初 redirect:error 的診斷未跟隨；已僅跟隨官方Location一次驗證。未猜造媒體網址。

## 審核與接口驗證

24項原後端測試、1項HTTP測試通過。真實6支本機影片逐支播放、6張poster及18張影格解碼、5支錯片禁用Approve、B可採用／排除、必填阻擋、裁切、修改後失效、localStorage、Search Again、JSON下載／複製均驗證。測試使用393×852觸控Chromium，沒有聲稱實體iPhone Safari測試通過。

從真實頁面匯出TEST-ONLY JSON，僅於隔離的一場景B測試副本，以實際本機預覽、SHA-256及34–40秒區間驗證 import → compile → 既有validateEditInput成功。測試只證明資料接口，並非使用者核准、正式下載品質驗收或自動剪輯。正式edit-timeline仍為awaiting_human_approval且clips=[]。未修改既有Composition、GPT-SoVITS或HyperFrames。

## iPhone與交付

目前工具未提供Codex正式受保護port preview建立能力，因此沒有可交付的雲端手機互動網址，沒有公開部署。請使用私有審核包；詳細步驟見 V101-REBUILD.md。雲端127.0.0.1:3112僅供本輪自動測試，不能當成iPhone入口。

審核包內保留來源、作者、授權URL及取樣時間。預覽為由正常GET影片轉製的本機低解析度副本，非正式素材hash，不適合當成已授權的公開素材庫；僅本次私人審核使用，審核後刪除不用的預覽。API原縮圖沒有永久儲存進包。
