# 可樂吉 V2.3：兩種視覺製程比較

## 範圍與保留
獨立 sibling 專案，原 V2.2 程式、素材、渲染輸出不變。保留舊 Composition 作為比較；新增 MilkEditorialA 與 MilkFootageB，各 120 格 / 30fps / 1080×1920。無配音、不改音訊系統、不做12秒延伸。

## A：精緻編輯式物件合成
改良同構物件素材的紙材與玻璃細節。牛奶盒以出液嘴為樞紐，先就位再傾倒；接觸陰影跟隨抬升而減弱。液流使用封閉體積形狀、重力路徑與細微流量變化，並非單一白線或擬真流體解算。流量以確定性粒子樣本累積到達杯內的體積，依杯腔截面積反解液高；液面不再用獨立 ease 曲線。杯後緣 → 液體 → 杯前反光的遮擋順序，杯口始終高於液面；接觸波紋只在落點且隨停流衰減。桌面前景、柔焦背景及物件接觸陰影建立層次。攝影機在動作後半平順移近玻璃杯，不突然切換。明確定位為風格化編輯式合成，不能視為實拍或物理解算。

## B：實拍影片加排版
使用 Pexels 6535488 / ROMAN ODINTSOV 的真實倒奶片。使用原片 4.0–8.0 秒，維持1倍速，不插補光流；轉成30fps是29.97到30的標準取樣。玻璃、液流、液面、光線與背景都取自同一鏡頭，不替換液體。保留原生動作，只做溫和暖色校正、直式構圖、微幅推近和精簡標題。素材未拍到牛奶盒，不宣稱展示盒子傾倒；內容也不能證明影片中奶的脂肪種類。

## 共用版面
米白／深藍／柔黃，主題「減脂不能喝全脂牛奶嗎？」不超過畫面上方小區域。無裝飾Icon、狀態碼、額外標籤或營養數字；物件動作為主。標題短距離進場，最後收束，不遮住液面。

## 逐秒與圖層
|時間|A|B|
|---|---|---|
|0–1s|盒子就位並傾斜，杯口清楚可見|實拍液流已在倒入；標題進場|
|1–2s|液流抵達，液量累積，微小接觸波紋|連續實拍，液面自然上升|
|2–3s|流量變細與落尾，攝影機開始移近|微幅構圖移近，維持玻璃完整|
|3–4s|盒子回正，杯內波紋衰減；鏡頭停穩|保持原片動作，不假造停流；標題收束|

A layers: 背景柔光 → 桌面 → 接觸陰影 → 盒子 → 玻璃後緣 → 腔內液體 → 空中液流 → 玻璃前緣／折射反光 → 共用標題。
B layers: 實拍原片（去聲音、暖調） → 精簡標題（影片上方負空間）。

先查看原始素材及關鍵格，再渲染4秒。主觀檢查涵蓋紙材／玻璃、液體接觸、比例、前後遮擋、攝影機、文字。機器檢查只驗規格與連續性，不能代替美術評價。正式MP4與輸出副本逐檔ffprobe及SHA-256；交付ZIP保留原始位元組。使用者回報的512×910副本尚未取得，原因保持未確認。
