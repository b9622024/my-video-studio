# V2.4 畫面品質檢查

## 預覽與修正
先輸出540×960、30fps、360格、12秒預覽，瀏覽器完整播放到結尾且無error；初稿檢查發現新中文字未在舊字型子集，以及份量觀察線偏離液面。已補齊字型逐字檢查、調整觀察線，再重新輸出預覽並完整播放後，才開始1080p正式版。不是只以解碼成功作美術判斷。

## 畫面觀察
- 同一真實杯子、液體、桌面及光向貫穿三段，不切到不同杯型／光線的無關stock；沒有圖片旋轉冒充液流。
- 字體深藍、細節柔黃與少量橘色，保留實拍負空間；標題64px，資料主標54px。杯子及持續倒入動作仍佔主要畫面，不使用整頁文字卡或Icon輪播。
- 資料線用同樣0–8g尺度，長度比例正確；7.4g／2.8g是相同200mL的計算值，讀取nutrition-v24.json，不用即時count-up數字模擬真實測量。
- 比較揭示及收束用短距離平滑動畫，底片沒有在4秒或8秒重新開始，鏡頭推近連續。沒有新增程式化食物、液體特效、回彈或漂浮。
- 來源與示意註記26px，在1080p可讀；540p相當於13px，若觀眾要核對細節可能需要暫停或閱讀附加來源。這12秒不是完整營養教育。
- 份量刻度為無單位概念尺，指示線依人工觀察的液面關鍵點近似對齊，不是容量追蹤或mL標定；已明示非量杯實測。
- 原片奶品種類與容量未知，不能從外觀判定全脂／低脂，也不能暗示此stock是福樂實測。商品僅作資料定義，不構成代言或優劣推薦。
- 片尾約0.53秒為刻意末格停留，液束同時停止影像運動；這是閱讀收束，不宣稱是自然停止倒奶。若未來需真人自然收手／停流，應改用包含完整停流的拍攝素材。

## 正式規格與重現
實際ffprobe、逐格解碼、master與交付副本雜湊、轉場前後灰階差、直接PNG與MP4對照、180→359→180跳轉及渲染時間見v24-qa-metrics.json。原始MP4另包ZIP，避免以播放器縮圖尺寸代替檔案解析度。

技術檢查排除黑畫面、規格錯誤、漏檔及跳轉狀態問題；沒有提供自動美術分數或宣稱使用者已驗收。請以實際12秒影片判斷節奏及閱讀量，再決定是否進入自動化。
