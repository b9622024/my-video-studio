# V2.3 美術比較與製作建議

這是製作方式比較，不宣稱任一版本已經達正式品牌影片標準。依據實際素材、六組同時點關鍵格（0／0.8／1.4／2／3／3.97秒）、120格影像與播放器檢查；程式只驗規格與重現性，沒有自動美術分數。

|面向|A 精緻編輯式合成|B 實拍混合動畫|
|---|---|---|
|物件美術|新精修atlas，紙面與玻璃高光較清楚，同色系統一；仍是可辨識的2.5D產品拼貼|真實玻璃厚度、桌面反射與背景景深，材質更可信；杯型不等同A，不能單純歸因為渲染器差異|
|液體自然度|體積累積、變細流尾、落點與衰減波紋已連動；流束仍偏規整、陰影細節少，有合成感|真實液束扭動、泡沫、接觸與微小波動較自然，本輪較有說服力|
|杯口與液面|後緣遮擋已局部挖除，前反光覆於液體上；液面保持杯口下方；白奶與米白背景對比偏低|液體與玻璃本來就在同一鏡頭，沒有分層接縫；四秒只增加部分份量，不誇大成滿杯|
|空間與陰影|修正桌面起點及接觸影位置；背景柔焦僅為層次，不是完整3D景深|天然景深與投影更豐富；後方第二個杯子無法單獨移除或重新安排|
|鏡頭|後半段9%推近及偏移，同一空間連續；盒子回正略具設計動作感，非真人手持|4.5%微幅推近，保留原片穩定性與正常速度；素材本身已在倒，沒有倒奶起點與停流|
|敘事連續性|有就位→傾倒→接觸→累積→回正→收束，起終可控制|連續四秒真實倒奶片段；牛奶盒在畫外，不能用它完成盒子→倒入的因果全景|

|PPT／插畫感|沒有場景輪播，但固定視角貼圖和規整液流仍有平面合成限制，不能稱已解決擬真問題|實拍行為持續發生，較少插畫感或PPT感；版面變化小是刻意讓動作作主角|

## 時間與重複利用

本環境本次單次正式Remotion渲染：A **17.84秒**，B **29.99秒**，不含素材準備、看圖修正、打包、來源查核與Git保存，非整體製作耗時。只量測4秒，尚未測30秒，不能保證線性倍增。

下一支相近鏡頭的人工製作粗估（非本輪實測／承諾）：素材已備妥時A約1–3小時調遮罩、出液口、杯腔、落點及視覺修正；B約20–60分鐘剪輯與排版，另需素材搜尋／授權查核時間。若拍攝新素材，需另計拍攝，不能以渲染秒數代表製片工時。

A可重用版面、鏡頭、流量計算與圖層架構，但每換容器必須重新校準輪廓、透視、杯腔及液流，無法自動套任何食物。B可重用裁切、字型與時間軸，真正的品質取決於找到同光線／同場景的適合影片；原片不能任意改視角或指定盒子姿態。

## 30秒 Reels 建議

優先採用B類實拍作為飲食物件動作的主體，A類用於比例／刻度／機制等需要精確控制的說明。先寫5–7個有明確任務的鏡頭（約每段3–6秒），優先找同一拍攝系列或自行拍攝，減少杯型、光線與桌面跳換。重要的倒奶起點、容器及停流最好拍攝一個完整鏡頭，再依旁白裁切；不要用30秒程式液體硬撐整篇。

只在必要的語句邊界加入簡短數據或標示，營養數據另查證；這支實拍不能證明全脂奶比較或脂肪含量。旁白未更動，後續如正式提供才對齊時間。本輪不延伸12秒、不建立龐大元件庫、不宣稱使用者已接受美術品質。

## 影像與技術驗證

兩版正式master和outputs副本各自ffprobe，1080×1920、30fps、120格、4.000秒、H.264、無音軌，來源／交付SHA-256一致。六張MP4對應格與直接Remotion PNG的RGB平均誤差<5/255；60→119→60重測像素一致。120格可解碼且無黑畫面。這些只排除技術問題，不證明動作有真實物理或品牌美術已合格。

解析度爭議另見RESOLUTION-AUDIT.md；未取得使用者512×910副本，原因尚未確認。下載masters ZIP可取得未經縮小的原始位元組。
